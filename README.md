# xxmathtools

一个用 PyQt5 写的**小学数学计算工具**，涵盖四则运算、分数、单位换算、几何计算和方程求解，
尽量贴着课本的写法给结果。

## 功能

程序分九个页面，窗口顶部是「计算设置」，底部是「历史记录」。

### 计算设置（顶部）

大多数页面的显示都受这里影响，改完立刻生效：

| 设置 | 说明 |
| --- | --- |
| 圆周率 | 「精确值 π」给 `4×π ≈ 12.57`；「取 3.14」按课本给 `4×3.14 = 12.56` |
| 保留小数 | 结果保留几位小数，可选 0 / 1 / 2 / 3 / 4 / 6 位 |
| 取整方式 | 四舍五入、进一法、去尾法 |
| 假分数显示成带分数 | 勾上后 `7/3` 显示为 `2又1/3` |
| 几何结果显示单位 | 勾上后显示 `面积 = 9 平方厘米` |

### 计算器

带**标准模式**和**科学模式**的计算器，覆盖高中之前的大部分运算：

| 能力 | 说明 |
| --- | --- |
| 基础运算 | 四则运算、括号、小数、负数（±）、百分号（`50%` = `0.5`） |
| 乘方与开方 | `x²`、`x^y`、`√`（平方根）、`³√`（立方根） |
| 三角函数 | `sin` `cos` `tan`，可在「角度 / 弧度」之间切换（默认角度，`sin 30° = 0.5`） |
| 反三角函数 | `sin⁻¹` `cos⁻¹` `tan⁻¹`，角度模式下结果按度给出 |
| 对数与指数 | `log`（常用对数）、`ln`（自然对数）、`e^x`、`10^x` |
| 其它 | 阶乘 `x!`、倒数 `1/x`、常数 `π` 和 `e` |

结果优先显示精确值（如 `sin(30) + cos(60) = 1`），分数同时给出小数近似。

### 计算

| 功能 | 说明 |
| --- | --- |
| 算式计算 | 输入完整算式，如 `3+5×2-(4÷2)`，按运算顺序直接出结果；支持括号、`^` 乘方、`sqrt()` |
| 分步计算 | 按运算顺序一步步列出来：先算哪一步、这一步得多少、此时算式变成什么样。过程会原样保留你写的 `×` `÷` 和括号顺序，不会变成 `-4/2 + 3 + 10` 那种机器写法 |
| 简便算法 | 提示能不能凑整、拆数或用运算定律：`25×4×8` 提示先算 `25×4`，`102×15` 提示拆成 `(100＋2)×15`，`(3+4-2)×5` 给出分配律的展开式 |
| 竖式演示 | 加、减、乘、除列竖式，除法给完整的长除法过程（等宽字体显示） |
| 乘方 / 开方 / 带余除法 | `2^10`、`√144`、`17 ÷ 5 = 3 余 2`，带余除法会顺手给出验算式 |
| 百分数 | `200 的 15%`、`30 是 200 的百分之几` |
| 价格计算 | 单价 × 重量 = 总价 |

### 分数

- **分数运算**：通分、约分、加减乘除，结果保持精确分数并附小数近似值
- **约分与通分**：不直接给答案，而是写出过程，如 `6/8` 的分子分母最大公因数是 2、`1/2 + 1/3` 先通分成 `3/6 + 2/6`
- **分数 / 小数 / 百分数互化**：输入任意一种写法，同时给出三种形式

### 数

- **因数与倍数**：分解质因数、最大公因数、最小公倍数
- **质数、奇偶与因数**：判断奇偶、质数还是合数，列出全部因数；可以列出 1000 以内任意范围的质数表
- **数的认识**：求近似数（`123456` 精确到万位 ≈ `12万`）、改写成用万或亿作单位

### 比与统计

- **解比例**：`3:4 = 6:x`，按「内项积 = 外项积」写出过程
- **按比分配**：`120` 按 `2:3:5` 分配，先求总份数和每份
- **平均数**：输入一串数，给总和、个数和平均数

### 换算

- **单位换算**：长度、面积、体积与容积、质量、时间、速度、人民币、温度，共 8 类，支持小数
- **复名数互化**：`1.5 小时 = 1小时30分`、`2米5厘米 = 2.05米`（长度、质量、时间、人民币）
- **时刻与日期**：从 `8:30` 到 `11:15` 经过多久（跨天自动按次日算）；某一天再过 N 天是几月几号、星期几

### 几何

- **平面图形**：长方形、正方形、三角形、平行四边形、梯形、圆、
  圆（已知直径）、圆（已知周长）、扇形、圆环 → 面积、周长、弧长
- **立体图形**：长方体、正方体、圆柱、圆锥 → 体积、表面积、侧面积
- **三角形判定**：判断三条边能不能围成三角形，并说明是等腰还是等边

含圆周率的结果会同时给出 π 形式和近似值，例如 `4×π ≈ 12.57`；
勾选「圆周率取 3.14」后则按课本写成 `4×3.14 = 12.56`。

### 解方程

一元方程求解。支持省略乘号（`2x`）、中文全角符号（`（x＋1）×2＝8`）、用 `^` 表示乘方；
没有等号时按“右边为 0”处理；无解显示「无解」，恒等式显示「任意实数都是解」。

点「分步解答」会针对**一元一次方程**列出移项、合并同类项、两边同除和代入检验的过程；
一元二次方程请用「解方程」直接求解。

## 运行

需要 Python 3，以及 PyQt5、sympy 两个库。

系统包方式（Debian / Deepin / UOS）：

```bash
sudo apt install python3-pyqt5 python3-sympy
cd xxmathrools
python3 小学数学工具.py
```

虚拟环境方式：

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
cd xxmathrools
python 小学数学工具.py
```

> 提示：从任意目录运行都可以，`calc.py` 会和主程序一起被找到。

启动时如果出现 `Could not find the Qt platform plugin "dxcb"`，这是 Deepin / UOS 上的常见提示，
会自动回退到标准 xcb，不影响使用。

## 测试

计算逻辑全在 `calc.py` 里，不依赖 Qt，可以脱离界面测试：

```bash
cd xxmathrools
python3 -m unittest test_calc -v
```

```bash
pip install pyinstaller
cd xxmathrools
pyinstaller -w -n 小学数学工具 小学数学工具.py
```

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `xxmathrools/小学数学工具.py` | 主程序：界面搭建、事件绑定、结果显示 |
| `xxmathrools/calc.py` | 计算逻辑层，不依赖 Qt，可单独测试和复用 |
| `xxmathrools/test_calc.py` | `calc.py` 的单元测试 |
| `requirements.txt` | Python 依赖 |

整个项目只依赖 Python，**没有 C++ / Qt Designer 相关文件**（早期的 Qt C++ 空壳已经移除）。

**界面是用代码构建的**。单位换算、复名数、几何计算都是数据表驱动的：

- 加一个新的换算类别：在 `calc.py` 的 `UNIT_TABLE` 里加一项
- 加一个新的复名数类别：在 `COMPOUND_CATEGORIES` 和 `_COMPOUND_UNITS` 里各加一项
- 加一个新的几何图形：在 `calc.py` 的 `GEOMETRY_SHAPES` 里加一项

`GEOMETRY_SHAPES` 的一项长这样：

```python
{'name': '正方形', 'group': '平面图形',
 'params': [('a', '边长')], 'func': _square},
```

其中 `func` 接收参数字典，返回「标签, 数值, 量纲」三元组的列表，
量纲取 `length` / `area` / `volume` 之一，用来决定结果显示成 `厘米`、`平方厘米` 还是 `立方厘米`：

```python
def _square(p):
    a = _positive(p, 'a', '边长')
    return [('面积', a ** 2, 'area'), ('周长', 4 * a, 'length')]
```

界面会自动出现对应的选项，不需要改动界面代码。

## 输入说明

所有输入框都做了校验：留空、非数字、除数为 0、负数开平方、三角形两边之和不够长等都会弹出友好提示，
出问题的输入框会标红并自动获得光标，程序不会崩溃。

竖式演示目前只支持非负整数（减法要求被减数不小于减数），因为小学阶段还不涉及负数竖式。
竖式用等宽字体显示，分隔线用 ASCII 的 `-`，避免中文全角字符把对齐撑歪。
