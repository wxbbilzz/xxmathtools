# xxmathtools

一个用 PyQt5 写的**小学数学计算工具**，涵盖四则运算、单位换算、几何计算和方程求解。

## 功能

程序分四个页面：

### 计算

| 功能 | 说明 |
| --- | --- |
| 算式计算 | 输入完整算式，如 `3+5×2-(4÷2)`，按运算顺序直接出结果；支持括号、`^` 乘方、`sqrt()` |
| 分数运算 | 通分、约分、加减乘除，结果保持精确分数，并附上小数近似值 |
| 因数与倍数 | 分解质因数、最大公因数、最小公倍数 |
| 乘方 / 开方 / 带余除法 | `2^10`、`√144`、`17 ÷ 5 = 3 余 2` |
| 百分数 | `200 的 15%`、`30 是 200 的百分之几` |
| 价格计算 | 单价 × 重量 = 总价 |

### 换算

长度、面积、体积与容积、质量、时间、人民币、温度，共 7 类，支持小数。

### 几何

- **平面图形**：长方形、正方形、三角形、平行四边形、梯形、圆 → 面积、周长
- **立体图形**：长方体、正方体、圆柱、圆锥 → 体积、表面积

含圆周率的结果会同时给出 π 形式和近似值，例如 `4×π ≈ 12.5664`。

### 解方程

一元方程求解。支持省略乘号（`2x`）、中文全角符号（`（x＋1）×2＝8`）、用 `^` 表示乘方；
没有等号时按“右边为 0”处理；无解显示「无解」，恒等式显示「任意实数都是解」。

## 运行

需要 Python 3，以及 PyQt5、sympy 两个库。

系统包方式（Debian / Deepin / UOS）：

```bash
sudo apt install python3-pyqt5 python3-sympy
cd xxmathrools
python3 小学数学工具.py
```

虚拟环境方式：

```bash
python3 -m venv venv
source venv/bin/activate
pip install PyQt5 sympy -i https://pypi.tuna.tsinghua.edu.cn/simple
cd xxmathrools
python 小学数学工具.py
```

> 提示：从任意目录运行都可以，`calc.py` 会和主程序一起被找到。

启动时如果出现 `Could not find the Qt platform plugin "dxcb"`，这是 Deepin / UOS 上的常见提示，
会自动回退到标准 xcb，不影响使用。

## 打包成可执行文件

```bash
pip install pyinstaller
pyinstaller -w -n 小学数学工具 小学数学工具.py
```

打包结果在 `dist/` 目录下。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `小学数学工具.py` | 主程序：界面搭建、事件绑定、结果显示 |
| `calc.py` | 计算逻辑层，不依赖 Qt，可单独测试和复用 |

整个项目只依赖 Python，**没有 C++ / Qt Designer 相关文件**（早期的 Qt C++ 空壳已经移除）。

**界面是用代码构建的**。单位换算和几何计算都是数据表驱动的：

- 加一个新的换算类别：在 `calc.py` 的 `UNIT_TABLE` 里加一项
- 加一个新的几何图形：在 `calc.py` 的 `GEOMETRY_SHAPES` 里加一项（参数列表 + 计算函数）

界面会自动出现对应的选项，不需要改动界面代码。

## 输入说明

所有输入框都做了校验：留空、非数字、除数为 0、负数开平方等都会弹出友好提示，程序不会崩溃。
